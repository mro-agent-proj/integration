### 1. 시나리오 29건 실행 결과 🔴 · 5.3 결과표

시나리오 원문: backend 저장소 `seed/scenarios.md` (S01~S23, V1~V6)

시나리오마다 모을 값

- [ ] 시나리오 번호, 등록부호, 입력한 증상
- [ ] 최종 상태 (ASSIGNED / HUMAN_REVIEW / 422)
- [ ] 실제 거친 단계 (CLASSIFYING → INVESTIGATING → REVIEWING), 재조사 횟수
- [ ] 실제 배정 부서, 또는 사람 검토 사유 (RETRY_LIMIT, AGENT_NEEDS_HUMAN 등)
- [ ] 근거 ID 목록 (MH-…, EV-SDR-…, EV-AMM-…)
- [ ] 처리 시간 (접수 → COMPLETED)
- [ ] 접수 충돌 V1~V6: 422 응답의 `details` (field, issue)
